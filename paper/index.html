Google Search Ranking & Discoverability Capstone

Abstract

Question: Can observed page-level search and content signals rank pages by refresh-review priority? Method: a transparent model is evaluated against a simple baseline on the same holdout. Result: the notebook computes held-out ranking metrics from the FlyRank dataset. Action: scores become a ranked editorial review queue with reason codes. Framing: this is decision support, not causal proof or a reconstruction of Google's ranking system.

1. Introduction / Problem statement

Editorial teams need a repeatable way to decide which pages deserve refresh review first when capacity is limited.

2. Data

The analysis uses an anonymized FlyRank search/content dataset. The unit of analysis is one page-level observation. Public outputs exclude client names, domains, private URLs, queries, credentials and raw exports.

3. Methodology

The target proxy is observed downward trend. Identifier-like and high-cardinality fields are excluded. A transparent logistic model is compared with a simple impressions-based baseline using the same stratified holdout.

4. Results

Run work/notebooks/capstone.ipynb to generate the model-vs-baseline metrics, ROC/PR charts and ranked recommendations from the actual dataset.

5. Limitations

The analysis does not prove causality, prove that refreshing a page will recover traffic, or reproduce Google's ranking algorithm. It is editorial decision support.

6. Ranked recommendations

The notebook produces a ranked queue with priority tiers and reason codes so recommendations remain auditable.

7. Reproducibility

Notebook: work/notebooks/capstone.ipynb. Generated assets belong in paper/assets/.
